# 羽毛球场地预约助手

江苏大学体育馆羽毛球场地自动预约工具（v2 · PySide6 版）。

基于 Playwright 驱动真实浏览器登录江苏大学体育场馆预约系统（`tybyy.ujs.edu.cn`），
在放号时刻自动开抢，并按「跨时段」策略匹配勾选的场地。

## 运行

```powershell
py -m pip install -r requirements.txt
py -m playwright install chromium
py venue_booking_tool_v2.py
```

启动后点击“打开预约页面”，在浏览器中手动登录；然后输入日期、时间段和场地优先级，点击“开始监控并自动选择”。工具找到可用场地后会停止，验证码、支付和最终提交由用户确认。

## 工作方式

- 预约当天 12:00 放号，程序在**当天 12:00:00 整**进入抢场状态（由「开抢时刻 = 放号时刻」保证）。代价是首次请求晚一个网络往返，靠开抢后 8 秒内的密集重试补偿。
- 开抢时刻前后约 8 秒内，探测间隔收窄到 0.05 秒；进入主循环的**第一轮**单独标记为「【12:00 定点筛选】」，保证日志里能看到这一下。
- 等待期间每 5 秒点击站点自带的刷新图标重拉数据（不整页刷新，不掉登录态），同时按探测间隔打接口匹配勾选的场地。
- 若到点时目标日期尚未出现在可约场次中，保持刷新等待最多 15 分钟，一出现立即筛选，不会退回到列表里的第一个场次。
- 系统一次只允许选 2 个场次。勾选多个时段 + 多个场地时，按**跨时段轮转**取：每个时段先各取 1 个，凑不满才回头补第 2 轮 —— 保证提交的 2 个尽量来自不同时段；只有 1 个时段有货时退回同时段取 2 个。
- 只要发现 ≥1 个可约场地就立即下单，一刻不等（抢场地是秒空的，先到手算赢）。

## 测试

`tests/` 下有三份离线自检（共 224 项），不需要联网，也不需要真实账号：

```powershell
py tests\selftest_v2.py      # 78 项：归一化 / 可用性判定 / 日期匹配 / 备选池与跨时段挑选 / 开抢时刻
py tests\ui_selftest.py      # 64 项：界面结构 + 方法绑定 + 场地映射 + 单次上限
py tests\test_api_mock.py    # 82 项：本地 mock 服务 + 真实浏览器页面上下文 + 主循环端到端
```

`test_api_mock.py` 需要 Playwright 的 Chromium（脚本里显式指定了完整版 `chrome.exe`）。

## 依赖说明

界面为 PySide6（含 Windows 亚克力效果），浏览器自动化为 Playwright。`browser_profile/` 存放登录态，请勿提交到版本库。
