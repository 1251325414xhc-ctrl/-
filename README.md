# 羽毛球场地预约助手

江苏大学体育馆羽毛球场地自动预约工具（v2 · PySide6 版）。

基于 Playwright 驱动真实浏览器登录江苏大学体育场馆预约系统（`tybyy.ujs.edu.cn`），
按预约日期放号时间自动等待、开抢并按优先级匹配场地。

## 运行

```powershell
py -m pip install -r requirements.txt
py -m playwright install chromium
py venue_booking_tool.py
```

启动后点击“打开预约页面”，在浏览器中手动登录；然后输入日期、时间段和场地优先级，点击“开始监控并自动选择”。工具找到可用场地后会停止，验证码、支付和最终提交由用户确认。

## 工作方式

- 预约当天 12:00 放号，程序默认在 **11:59** 提前一分钟进入筛选状态。
- 放号前最后 5 秒探测间隔自动收窄到 0.05 秒；跨过 12:00 的第一轮单独标记为「【12:00 定点筛选】」，保证日志里能看到这一下。
- 等待期间每 5 秒点击站点自带的刷新图标重拉数据（不整页刷新，不掉登录态），同时按探测间隔（默认 0.4 秒）打接口匹配勾选的场地。
- 若 11:59 时目标日期尚未出现在可约场次中，保持刷新等待最多 15 分钟，一出现立即筛选，不会退回到列表里的第一个场次。
- 系统一次只允许选 2 个场次：按「时段优先」顺序取前 2 个可约场地提交。

## 依赖说明

界面为 PySide6（含 Windows 亚克力毛玻璃效果），浏览器自动化为 Playwright。`browser_profile/` 存放登录态，请勿提交到版本库。
